# FCO AI · Métricas

Dashboard público con las métricas del equipo **FCO AI** en el AWS Agentic Football Cup:
resultados, tiros, posesión, goles por tramo, mezcla de comandos, latencias por jugador,
tabla del torneo y el seguimiento de los experimentos de optimización.

Ver en vivo: https://estebanp80.github.io/fco-ai-dashboard/

La página se genera automáticamente desde un repositorio privado; este repo contiene solo el
resultado (`index.html`).
